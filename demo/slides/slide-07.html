06 Bug Catch #2 Not in our prompt scope — Bob found this independently

A heap overflow, self-detected.

kopen.c — http_open(), reading the response header into a 64 KB calloc buffer

Before 
while (read(fd, buf + l, 1)) {  if (buf[l] == '\n' && l >= 3)    if (strncmp(...) == 0) break;  ++l;   /* no upper bound */}buf[l] = 0;  /* l reaches 0x10000 */
After 
while (read(fd, buf + l, 1)) {  if (buf[l] == '\n' && l >= 3)    if (strncmp(...) == 0) break;  ++l;  if (l >= 0xffff) break;  /* bound */}buf[l] = 0;  /* always in range */
A header larger than 64 KB walks l to 0x10000, and buf[l] = 0 writes one byte past the heap allocation. The loop now stops one byte short.
